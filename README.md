# Huilin

A single-page site for Huilin, a fictional luxury house. Black, ivory, and one gold accent. No build step.

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Sections

Hero, featured collection, brand story, editorial lookbook, newsletter, and footer. Collection pieces open a detail dialog. The newsletter stays in the browser and confirms a valid address on the page.
